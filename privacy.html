개인정보처리방침

Mailbot · 마지막 고친 날 2026년 9월 17일

Mailbot 은 사용자 본인의 PC 에서 도는 개인용 도구입니다. 회원 가입이 없고, 운영하는 서버가 없으며, 만든 사람이 사용자의 데이터를 받아 보지 않습니다.

1. 어떤 정보를 다루는가

사용자가 구글 계정으로 권한을 준 사서함 한 곳에서 아래를 읽습니다.

  • 메일의 제목, 보낸 사람, 받은 시각, 본문
  • 메일에 붙은 첨부파일
  • 메일에 붙은 라벨

2. 왜 다루는가

첨부파일을 사용자가 정해 둔 폴더에 저장하고, 누가 언제 무엇을 보냈는지 기록으로 남기기 위해서입니다. 이미 처리한 메일을 두 번 처리하지 않도록 라벨을 붙이는 데에도 씁니다. 다른 목적에는 쓰지 않습니다.

3. 어디에 저장하는가

읽어 온 내용은 사용자 PC 안에만 저장합니다. 만든 사람을 포함해 누구도 접근할 수 없는 사용자 개인 컴퓨터의 폴더이며, 인터넷으로 전송하지 않습니다.

구글에서 받은 인증 토큰도 사용자 PC 의 파일 하나에 소유자만 읽을 수 있는 권한으로 저장합니다.

4. 누구에게 제공하는가

제공하지 않습니다. 광고에 쓰지 않고, 판매하지 않으며, 사람이 읽어 보는 용도나 인공지능 모델을 학습시키는 데 쓰지 않습니다. 구글 API 서비스 사용자 데이터 정책의 제한적 사용 요건을 지킵니다.

5. 얼마나 보관하는가

사용자가 지울 때까지 사용자 PC 에 남습니다. 폴더를 지우면 함께 사라집니다.

6. 권한을 거두는 방법

구글 계정의 보안 · 타사 앱 액세스에서 이 앱의 권한을 지우면 그 즉시 사서함에 접근하지 못합니다. 사용자 PC 의 토큰 파일과 저장된 폴더를 지우면 남은 자료도 없어집니다.

English summary

Mailbot is a personal tool that runs on the owner's own computer. It reads messages, attachments and labels from a single Gmail mailbox the user authorizes, saves the attachments to local folders, and applies a label to processed messages. All data stays on the user's computer. Nothing is transmitted to any server operated by the developer, sold, used for advertising, or used to train AI models. Mailbot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: aidataknbank@gmail.com.
