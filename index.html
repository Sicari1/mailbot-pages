Mailbot

지정한 Gmail 사서함으로 온 메일에서 첨부파일을 꺼내 정리하는 개인용 도구입니다.

무엇을 하는 도구인가

협업 상대가 정해진 주소로 자료를 메일로 보내면, 이 도구가 그 메일을 확인해 첨부파일을 내려받고 미리 정해 둔 폴더에 갈래별로 저장합니다. 압축파일은 풀어 두고, 누가 언제 무엇을 보냈는지 기록으로 남깁니다.

어디서 도는가

사용자 본인의 PC 에서만 돕니다. 서버에 올라가 있지 않고, 웹에서 가입해 쓰는 서비스도 아닙니다. 계정 소유자 한 사람이 자기 사서함에 쓰는 도구입니다.

어떤 권한을 쓰는가

Gmail API · gmail.modify
메일과 첨부파일을 읽고, 처리를 마친 메일에 라벨을 붙이는 데 씁니다. 이 권한 하나만 요청합니다.

  • 메일 내용과 첨부파일을 읽습니다.
  • 처리를 마친 메일에 적재완료 라벨을 붙여 두 번 처리하지 않게 합니다.
  • 메일을 지우지 않습니다. 사서함 설정도 바꾸지 않습니다.

데이터를 어떻게 다루는가

읽어 온 메일과 첨부는 사용자 PC 안에만 저장합니다. 외부 서버로 보내지 않고, 광고에 쓰지 않으며, 다른 사람이나 회사에 넘기지 않습니다. 자세한 내용은 개인정보처리방침에 적어 두었습니다.

In English. Mailbot is a personal tool that runs on the owner's own computer. It reads messages and attachments from one Gmail mailbox, saves the attachments into local folders, and labels processed messages. It requests only the gmail.modify scope. No data leaves the user's computer, and nothing is shared with third parties. See the Privacy Policy.
